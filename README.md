# RedHelen V2

ქართული-first, სამენოვანი ონლაინ მაღაზიის რეალური backend/frontend საწყისი სისტემა.

## ჩაშენებული
- ქართული / English / Русский ენის არჩევა
- პროდუქციის კატეგორიები
- პროდუქტის დეტალური გვერდი
- კალათა
- შეკვეთის გაფორმება
- უნიკალური Order ID: RH-YYYY-0001
- SQLite მონაცემთა ბაზა
- ადმინისტრატორის ავტორიზაცია
- პროდუქტების დამატება/რედაქტირება/წაშლა
- შეკვეთების ნახვა და სტატუსის შეცვლა
- მარაგის კონტროლი
- მომხმარებლის საკონტაქტო მონაცემები
- ფასის, თვითღირებულებისა და მოგების დათვლა
- შეკვეთის CSV ექსპორტი
- responsive/mobile-first დიზაინი

## გაშვება
1. დააყენეთ Node.js 20+.
2. ამ საქაღალდეში გაუშვით `npm install`.
3. `.env.example` გადაარქვით `.env` და შეცვალეთ ADMIN_PASSWORD და SESSION_SECRET.
4. გაუშვით `npm start`.
5. გახსენით `http://localhost:3000`.
6. ადმინისტრაცია: `http://localhost:3000/admin/login`.

## ონლაინ გადახდა
საბანკო ონლაინ გადახდის რეალური გააქტიურებისთვის საჭიროა შესაბამისი merchant ანგარიშის/API credentials. ამ V2-ში შეკვეთის სისტემა მზადაა provider-ის დასამატებლად; საიდუმლო API გასაღებები კოდში არ უნდა ჩაიწეროს.

## წარმოებაში გაშვებამდე
- HTTPS
- ძლიერი ADMIN_PASSWORD და SESSION_SECRET
- PostgreSQL/MySQL-ზე გადასვლა მაღალი დატვირთვისთვის
- სარეზერვო ასლები
- რეალური გადახდის provider-ის webhook-ები
- ელფოსტა/SMS/WhatsApp provider
- რეალური დომენი და hosting
